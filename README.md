# Dämonenschwert 11

Dämonenschwert 11 is a Minecraft plugin that adds a powerful demonic sword to the game. With a simple right-click, players can summon a massive demon that acts as their loyal companion, protector, and mount. The demon features a unique design with black, red, and violet colors, wings that allow it to fly, and a wide range of abilities to aid its summoner in battle. The demon is highly durable, with 1000 hearts and constant regeneration, making it nearly unkillable. The plugin includes various attacks and abilities such as summoning additional protectors, shooting a powerful laser, and manipulating elements like fire, water, wind, and earth.

## Install

1. Download the plugin JAR file from the [releases page](https://github.com/EnderDevelopment/Daemonenschwert-11/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. Obtain the Demon Sword by using the command `/givedemonsword`.
2. Right-click with the Demon Sword to summon the demon.
3. The demon will follow you and protect you from enemies.
4. Use the demon's abilities by interacting with it or using specific commands.
